# Техническое задание на мобильный дизайн

## Платформа и технология
* **Тип:** Мобильный сайт.
* **Управление:** автономное приложение (Next.js / Telegram Mini App), данные в `localStorage`.
* **Аудитория:** мужчины и женщины 20-60 лет, современные.
* **Стиль:** строго по брендбуку клиники, сдержанный. Без кричащих цветов и дешёвых анимаций.

## Состав экранов
1. **Авторизация**: Ввод телефона с маской, СМС-код (4 цифры), таймер, состояния ошибок.
2. **Главный экран**: Карточки (ближайшая запись, план лечения, финансы), быстрые действия, таббар.
3. **Мои записи**: Список (предстоящие/прошедшие), статусы, действия (отмена, перенос, календарь).
4. **Запись на приём**: Пошаговый процесс (услуги -> врачи -> календарь), подтверждение.
5. **Зубная формула**: Интерактивная схема 32 зубов, цветовая индикация состояний, легенда.
6. **Карточка зуба**: Диагноз, история лечения, материалы, гарантия.
7. **План лечения**: Группировка по этапам/зубам, цены, статусы выполнения, общая сумма.
8. **Мои счета**: Список счетов, статусы оплаты, онлайн-оплата.
9. **Профиль**: Личные данные, лечащий врач, настройки уведомлений.
10. **Контакты**: Карта, адрес, быстрые звонки, часы работы.
11. **Профилактика**: Рекомендации, прогресс-бары до следующего визита, плановые осмотры.

## Общие требования
* **Навигация**: Нижняя панель (Главная, Записи, Формула, Счета, Ещё).
* **Сетка**: База 390px (iPhone 14).
* **Тон**: Премиум, приглушенная гамма, белый фон, минимум теней, тонкие линии.
* **Типографика**: Чистый гротеск.
